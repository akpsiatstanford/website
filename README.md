This is the website for Stanford AKpsi.

It is built with the [Next.js](https://nextjs.org) framework (bootstrapped with [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app)) and deployed using the [Vercel Platform](https://vercel.com/).

See the [Webmaster guide](https://docs.google.com/document/d/1Ivy1gMq7q2sGG2T5Z2cxlfP_csxojcub58KMtQZ23Sk/edit?tab=t.0) in the shared AKPsi drive (attached to akpsiatstanford@gmail.com) for details on how to update and maintain the website.

To test locally, run
```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```
and open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
